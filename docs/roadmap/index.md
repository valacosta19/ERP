# Roadmap — ERP Peluquería

Iniciativas planificadas para el desarrollo del sistema. Cada archivo documenta el contexto, la arquitectura y las fases de implementación de una mejora mayor.

Los ítems de fase actual (feature del sprint en curso) se documentan en `PROJECT_STATE.md` y los `PHASE_N_SUMMARY.md`. Este directorio es para **planificación a futuro**: cosas aprobadas conceptualmente pero no iniciadas todavía.

## Cómo agregar una iniciativa

1. Crear un archivo `nombre-de-la-iniciativa.md` en esta carpeta.
2. Agregar una fila en la tabla de arriba.
3. El archivo debe incluir: contexto/por qué, enfoque técnico, fases, archivos críticos y checklist de verificación.
